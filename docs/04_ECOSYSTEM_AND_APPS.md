# APPS, AI, GAMING AND NEXUS ECOSYSTEM

## Default browser
- Google Chrome latest stable Linux release from Google's official channel/repository.
- Do not rebrand as NEXUS browser.
- Support account sync, extensions, bookmarks, downloads, incognito, Safe Browsing, hardware acceleration and official updates, subject to Google's product behavior.
- Install during setup or first online setup if redistribution/licensing makes ISO bundling unsuitable.

## NEXUS Store
- Search, categories, details, screenshots, source, version, publisher/signature, permissions, install/update/uninstall.
- Native packages and Flatpak/Flathub where available and appropriate.
- Show dependencies, disk space, progress from real package manager events, errors and rollback guidance.
- Do not show fake catalog entries as installable.

## NEXUS AI
- Chat and voice input/output.
- Model/provider configuration and secure API key storage.
- Optional local model support with hardware requirement display.
- System diagnosis based on actual logs and telemetry the user permits.
- Explain findings, confidence and proposed action.
- Repair requires permission and explicit confirmation; show commands/actions before execution.
- No destructive operation without a second confirmation.
- File search only within user-authorized locations.
- Automation with visible rules, pause/disable and audit history.
- Preference memory controls and clear privacy explanation.
- Offline mode must state what works offline and what requires a network/model.

## Gaming Center / Console Mode
- Full-screen controller-friendly shell.
- Game library and Steam integration.
- Proton compatibility status where available.
- Per-game performance profiles.
- FPS overlay only where supported.
- CPU/GPU/RAM monitoring, screenshot and recording.
- Controller mapping and calibration.
- Resolution/display options and safe exit to desktop.
- Never guarantee compatibility for every game or anti-cheat.

## Ecosystem
- NEXUS Connect: phone-PC file transfer, clipboard sharing, notifications and screen mirroring where secure.
- NEXUS Cloud: optional encrypted sync/backup, account/session management and restore.
- NEXUS Developer Studio/SDK: APIs, app packaging, debugging, publishing and docs.
- Compatibility Lab: test reports and known compatibility.
- Automation Center: user-created automations with permission boundaries.
- Remote Support: authenticated, consent-based sessions with visible session indicator.
- Multilingual support including Hindi and English, with translation/localization workflow.
- Multi-user, guest accounts and parental-control options with clear account-owner controls.
